Documentation, project files and tools from the irreguLAB-Y research project conducted by the irreguLAB.

# Notice

The documentation is not yet finished. The repository will be updated in the next few months. If specific data is needed, contact the authors.

# Overview

## Contents

This repository contains both the research product (final iteration of digital tools and their usage documentation), compiled experiments as well as their evaluation (fabrication and design files in the making of the demonstrator aggregation).

## Repository Structure

```
augmented-gleaning/

	README.md # main readme
	assets/ # images and videos for README and docs
	
	LICENSE
	CITATION.cff
	
	docs/
		USAGE.md # usage quick start
		METHOD.md # script and code explanation
	
	tools/ # Grasshopper and Python tools
		lib/ # Python libraries and classes
		comp/ # Python Grasshopper components
		augmented-gleaning.gh
		fabrication-geometry.gh

	process/ # documentation of used tools and processes
		fabrication/ # fabrication related documentation
		MR/ # Mixed Reality related documentation

	data/
		design/
		representation/
		fabrication/
		geometry/
	
	results/
		representation/
		fabrication/
		geometry/
```
